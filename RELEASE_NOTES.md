# Release notes

## 1.0.0 (17 October 2026)

First public release of Gargi:
- **Gargi:** the chat model, with step-by-step thinking on maths and multi-turn conversation.
- **Gargi-Base:** the pretrained base model.
- **Gargi-GGUF:** Q8_0, Q4_K_M and f16 builds.
- **Gargi-MLX / Gargi-MLX-4bit:** builds for Apple silicon.

Licence: Apache-2.0. Known limitations are listed in the README (maths and knowledge below newer models trained on far more data; reliable recall to ~16K tokens; not safety-tuned).
